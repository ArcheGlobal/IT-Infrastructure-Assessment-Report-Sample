Technical Terms & Acronyms

MFA (Multi-Factor Authentication)
Security mechanism requiring two or more verification factors to access systems. Industry standard for preventing credential-based attacks (81% of breaches per Verizon DBIR).
PAM (Privileged Access Management)
Solution for securing, controlling, and monitoring privileged accounts (admin, root, service accounts). Critical for preventing lateral movement in breaches.
SPOF (Single Point of Failure)
Infrastructure component whose failure would cause complete service outage. Eliminated through redundancy and high-availability architecture.
RTO (Recovery Time Objective)
Maximum acceptable time to restore service after disruption. Industry standard: Critical systems ≤4 hours, Standard systems ≤24 hours.
RPO (Recovery Point Objective)
Maximum acceptable data loss measured in time. Industry standard: Critical data ≤15 minutes, Standard data ≤24 hours.
Zero Trust Architecture
Security model assuming no implicit trust. Every access request verified regardless of location. NIST SP 800-207 standard.
HSRP/VRRP
Hot Standby Router Protocol / Virtual Router Redundancy Protocol. Provides automatic failover for network gateway redundancy.
SIEM (Security Information & Event Management)
Centralized security monitoring collecting and analyzing logs from all systems. Industry standard for threat detection and compliance.
Immutable Backup
Backup that cannot be modified or deleted for specified period. Critical defense against ransomware (prevents encrypted backup deletion).
ITIL v4
Information Technology Infrastructure Library version 4. Global framework for IT service management best practices.
COBIT 2019
Control Objectives for Information Technology. Framework for IT governance and management from ISACA.
ISO 27001
International standard for information security management systems. Certification demonstrates security program maturity.
